# Safety And Privacy

## 禁止保存

本项目禁止保存：

- 客户姓名。
- 手机号。
- 地址。
- 身份证。
- 订单号原文。
- 聊天记录原文。
- 账号密码。
- Token。
- Cookie。
- API Key。

## 允许保存

允许保存：

- 脱敏后的示例问题。
- 场景分类。
- 意图标签。
- 标准话术。
- SOP。
- 质检规则。
- 转人工规则。
- 非密钥配置。

## 租户与网关边界

- 受登录保护的业务请求只从服务端会话取得租户标识；知识、工单、通知、库存、场景、审计和试点报表均按该标识隔离。
- 旧版单店 SQLite 数据首次升级时会一次性迁入配置的默认租户命名空间，不会被静默删除。
- 应用层校验允许主机、写入来源、CSRF、受保护写操作频率和响应安全头；公网部署仍须在反向代理或云网关配置 TLS、按来源限流、访问日志、DDoS 防护与告警。
- API Key、平台 OAuth 凭据和 Webhook 密钥只允许在部署运行时的密钥系统或环境中提供，禁止进入租户业务表、审计正文、报表和源码包。

## 高风险场景

以下场景默认转人工：

- 退款赔付争议。
- 食品安全投诉。
- 法律威胁。
- 平台投诉升级。
- 用户情绪激烈。
- 涉及隐私信息修改。
- 涉及金额承诺。
